# 第22篇：高阶重构与限制器

本目录是《把方程算明白》第22篇的可执行配套材料。Python 3 标准库求解，不需要安装第三方计算库。公开副本位于 `pdebook-assets/code/pde-022/`，与作者仓库的实验文件保持相同内容。

## 运行

在本目录执行：

```bash
python src/reconstruction.py
```

程序根据脚本自身位置寻找配置和输出目录，也可以从其他工作目录传入脚本完整路径。可选参数为 `--config 配置路径`、`--output 输出目录`。默认重新生成 `results/` 下六份 CSV 和 `run.txt`。全部算例先完成计算，参数不合法时不写结果；要求正速度、正时间及 CFL 不超过一。

已使用 Python 3.12.14 实际运行21组算例，共3120次更新。另目录按公开代码布局执行，结果逐字节一致。CSV 显式使用 LF 行结束符。

## 数学问题和参数

求解无量纲周期区间 [0,1] 上的常速平流 `u_t + c u_x = 0`，速度 c=1，终止时刻 T=0.5。数值未知量是每个单元的平均值。N 个均匀单元的宽度为 h=1/N，时间步长为 dt=T/steps，下标按模 N 循环。

- 光滑波：初值 `1 + 0.5*cos(2*pi*x)`，四级 N=40、80、160、320，对应50、100、200、400步，CFL=0.4。
- 矩形脉冲：[0.2,0.43) 内为一，其余为零，周期延拓；N=160，200步，CFL=0.4。终止脉冲平移至 [0.7,0.93)。输入和误差参考都用精确单元平均；不能把中心点值当作参考。
- 常数保持：初值2.5，N=40，50步，CFL=0.4。
- 整格平移：相同脉冲，N=80，40步，CFL=1；每步向右平移一个单元。

上述七组参数各使用三种斜率，共21组。`upwind` 取零斜率；`centered` 用左右单元平均的中心差分；`minmod` 取左右同号斜率中绝对值较小者，否则取零。三者都用线性轮廓平移得到的时间平均通量：

```text
right_face_flux[i] = c * (U[i] + (h-c*dt)/2 * slope[i])
new_U[i] = U[i] - dt/h * (right_face_flux[i] - right_face_flux[i-1])
```

每份界面通量只计算一次，再用于相邻两个单元。没有在更新后裁掉负值或过高值。`minmod` 在本篇的均匀周期网格、正速度和 CFL 条件下保持初始数值值域，并满足总变差不增；中心斜率不保证这些性质。

常规细化选 CFL=0.4。CFL=0.5 会使中心斜率格式的首个三阶矩误差抵消，不宜拿这一特殊参数代表一般二阶表现。六单元手算另用0.5以简化分数；整格平移另用1检查特殊极限。

## 数据文件

| 文件 | 数据行数 | 含义 |
| --- | ---: | --- |
| cells.csv | 2640 | 每个终止单元的左右界面、初始平均、精确平均、数值平均及有符号误差 |
| history.csv | 3141 | 包含初始层的逐层时间、总量、漂移、最值、总变差、每步变化和两种误差 |
| summary.csv | 21 | 每组配置、终止统计及全程最大总量漂移、局部残差与总变差增加量 |
| convergence.csv | 12 | 三种斜率的四级光滑误差及相邻网格的观测阶 |
| hand.csv | 18 | 三种方法各六个单元的一步斜率、左右通量、新值与总变差 |
| reconstruction.csv | 18 | 六组三点数据分别采用三种斜率时的重构端点 |
| run.txt | — | Python版本、实际行数和总体守恒残差 |

`hand.csv` 是独立的小网格手算：六单元旧值 (0,0,1,1,0,0)，h=1、c=1、dt=0.5，周期长度为六，不与上面的单位区间混用。`reconstruction.csv` 也取 h=1。

总量为 `h*sum(U)`；周期总变差为 `sum(abs(U[i]-U[i-1]))`，包括首尾差。`l1_error` 为 `h*sum(abs(U-exact))`，`max_error` 为最大平均值绝对误差。观测阶为 `log2(E(h)/E(h/2))`，首级留空。局部平衡残差为 `abs(h*(new-old)-dt*(left_flux-right_flux))`；`history.csv` 的 `previous_step_balance` 是到达当前层的上一步最大局部残差，初始层记零。

结果中中心斜率的脉冲最值约为 -0.060513 和1.061784。minmod 控制越界、比零斜率减小整体误差，但在光滑波极值附近也会限制斜率；本组最细两级的 E1 观测阶约1.89，最大误差的观测阶约1.29。守恒、无越界与误差较小是不同判断，不能相互替代。
