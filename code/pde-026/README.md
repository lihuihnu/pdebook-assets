# 第26篇配套计算：有限元中的边界条件

在区间[0,1]上解−u''=f，采用连续分片线性有限元和准确单元积分。核心只用Python标准库；没有NumPy、SciPy或有限元软件依赖。

```bash
python src/boundary_conditions.py
```

入口按自身位置寻找config/problems.json和results/，不依赖当前工作目录。也可指定：

```bash
python src/boundary_conditions.py --config config/problems.json --output results
```

## 数据约定

- D表示Dirichlet函数值。N表示外法向导数：左端q0=−u'(0)，右端q1=u'(1)。输入已经使用外法向，所以两端的N项均加到右端。
- 每个端点指定一种条件。源项可为0、1或x；载荷用准确多项式公式积分。
- 纯Neumann先检查载荷之和，再用pin_left或zero_mean选择代表。没有载荷投影或源项修正。zero_mean由折线积分计算，不使用节点算术平均。
- 相容性浮点容差为64×机器精度×max(1,右端各分量绝对值之和)。通过检查只说明载荷和在该舍入容差内；仍用未修改的原矩阵和右端核对全部行。
- 含D端点的系统检查自由行；D端点原积分行的残差不是求解失败。纯N系统检查所有原行，包括临时固定时删去的那一行。

## 实际计算

配置包含7张网格和10类相容问题，共70组求解：非零DD、左右混合条件、纯N固定左值/零均值、漏项/错号对照、零源线性解和线性源项。主网格为0、1/4、1/2、1。

14组不相容纯N输入由正常求解入口拒绝。diagnostics.csv另外保存明确改过的系统，用于演示强行固定节点、漏掉D列贡献和使用节点算术平均的错误；这些诊断值不属于原问题的合格解。

| 文件 | 内容 |
| --- | --- |
| matrix.csv | 全局帽函数刚度矩阵，449项 |
| elements.csv | 三种源项的114组局部载荷 |
| loads.csv | 450个节点的体载荷、边界增量与原始右端 |
| reduced.csv | 3522个约束消元后的矩阵项及对应右端 |
| nodes.csv | 450个实际节点解、参考值、误差与原行残差 |
| slopes.csv | 380个实际单元斜率 |
| summary.csv | 70组求解的残差、常数平移、积分均值等 |
| profiles.csv | 五个主网格算例的2005个函数采样 |
| rejected.csv | 14组被拒绝的不相容输入 |
| diagnostics.csv | 16行错误操作诊断 |
| run.txt | 实际运行摘要和Python版本 |

解析多项式只在求解完成后核对，不参与设置未知节点值。零均值纯N解与连续零均值解可存在相同的节点常数偏差；shape_error先对齐左端值，只比较相差常数以外的部分，不等于一般意义的节点误差。

本次运行使用Python 3.12.14。数据和日志均由入口实际生成。
