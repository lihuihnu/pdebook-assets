# 波动方程与二阶时间差分：配套计算

求解无量纲问题 u_tt=c²u_xx，0<x<1，两端位移固定为零。核心算法为显式三层中心差分，第一层同时使用位移、初速度和半个时间步平方的初始加速度。只需 Python 标准库，不需要 NumPy、SciPy 或 Matplotlib。

在本目录中运行：

```bash
python src/wave_centered.py
```

也可以从任意目录运行脚本的完整路径。默认配置和结果路径相对于脚本定位；显式指定时，路径相对于运行命令的当前目录：

```bash
python src/wave_centered.py --config config/wave.json --output results
```

程序会覆盖所选输出目录下的同名结果。记录数据使用 Python 3.12.14。算法不调用模态闭式来推进，正弦闭式只用于独立核对。代码中的 `yield` 每次向实验记录部分交出一层节点值，求解器本身只保留推进需要的最近几层。

## 参数与参考解

全部参数见 `config/wave.json`，本篇 c=1。

- 脉冲：中心0.35、半宽0.1；支撑内 g(x)=[1-((x-0.35)/0.1)²]^6，外部为零；v=-g'。N=200，M=250，T=1，dt=0.004，Courant数0.8。参考为 g(x-t)-g(2-x-t)，有效到反射波再次抵达左端之前。本参数下该时间为1.55，实验在T=1停止。
- 正弦：g=sin(pi*x)，v=pi*sin(pi*x)；参考为 sin(pi*x)[cos(pi*t)+sin(pi*t)]。N=20、40、80、160，M=N，T=0.8，dt=0.8/N。固定Courant数0.8，同时细化时间与空间。

核心函数假定调用者提供等长、零端点的位移/速度列表及合法步数。实验入口检查配置、Courant数范围、解析参考的有效时间和快照是否对应真实时间层；不静默把不合法参数调整到另一张网格。若改动波速，程序会相应调整两种解析参考和脉冲初速度。默认正弦初速度系数保留为pi，波速不为1时连续解的时间正弦系数改为1/c。

## 透明输出

| 文件 | 内容 |
| --- | --- |
| snapshots.csv | 脉冲在t=0、0.4、0.6、0.9的全部节点值、解析参考及有符号误差，共804行 |
| final_nodes.csv | 脉冲及四组正弦计算的终止节点值与参考，共505行 |
| history.csv | 全部550对相邻时间层的能量及整层最大误差 |
| summary.csv | 5次计算的参数、终点/全时段误差、能量偏差和方程残差 |
| convergence.csv | 四级正弦终点误差及相邻两级误差比 |
| run.txt | Python版本、实际运行状态、自检及结果摘要 |

`history.csv`中`time=n*dt`用于当前整层的`max_error`，`half_time=(n-0.5)*dt`用于该行的能量；不要混用两个时间坐标。`energy`是由相邻层斜率交叉乘积构造的H，`positive_energy`是使用平均位移斜率平方的H_tilde。后者非负但一般不守恒。误差比为前一较粗网格的误差除以当前较细网格的误差，不是单独的时间收敛阶。

每个时间层都在运行时检查有限性、边界、误差和相邻层能量；不保存完整时空节点场。`max_scaled_residual`是三层更新式左右相减后的残差，再除以各项绝对值之和与1的较大者；它衡量差分方程满足程度，不是连续PDE误差。

启动自检包括手算第一步/第二步、零解、旧列表不被覆盖、离散分部求和，以及N=2、3、10与Courant数0.25、0.8、1的36条正弦模态轨迹。对照含非零初速度的离散闭式，检查30步内节点与能量；同一套实现还检查能量下界。实验不做计时，也不声称能量守恒就等于波形准确。
