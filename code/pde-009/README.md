# pde-009：数值误差、网格细化与收敛

这是《把方程算明白》第 9 篇的公开配套代码。实验研究一维 Poisson 边值问题

$$-u''(x)=12x^2,\qquad 0<x<1,$$

$$u(0)=u(1)=0,$$

其解析解为

$$u_\star(x)=x-x^4.$$

程序依次取 `N = 4, 8, 16, 32, 64`，对每个等距网格重新组装并求解有限差分系统，再计算最大节点误差

$$E_h=\max_i|U_i-u_\star(x_i)|.$$

## 运行

从本仓库根目录运行：

```bash
python3 code/pde-009/src/poisson_refinement.py
```

运行环境：

- Python 3.13.5；
- 第三方 Python 依赖：无。

脚本生成：

```text
code/pde-009/results/convergence.csv
```

## 实际结果

```text
N    h           max_error       ratio       order
 4   0.25000000   0.0156250000            -          -
 8   0.12500000   0.0039062500     4.000000   2.000000
16   0.06250000   0.0009765625     4.000000   2.000000
32   0.03125000   0.0002441406     4.000000   2.000000
64   0.01562500   0.0000610352     4.000000   2.000000
```

程序还会逐节点核对当前特殊算例的解析误差关系

$$U_i-u_\star(x_i)=-h^2x_i(1-x_i),$$

以及偶数 `N` 时

$$E_h=\frac{h^2}{4}.$$

因此每次把 `h` 减半，最大节点误差缩小为原来的四分之一，观测收敛阶为 2。

这里的高斯消元只用于透明地复现本文的小规模有限差分实验，不作为大规模 PDE 线性系统的求解器建议。
