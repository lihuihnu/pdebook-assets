# 第17篇：CFL、数值耗散与数值色散

本目录计算单位周期区间上的常速平流方程 `u_t+c*u_x=0`，对照一阶迎风与 Lax–Wendroff 格式。只保存 `x_i=i/N`、`i=0,...,N-1` 的节点，右端点不重复存储。初值由配置中的余弦模态相加得到，精确解为初值平移 `c*t`。全部量均已无量纲化。

## 运行

在本目录执行：

```bash
python src/transport.py
```

程序只用 Python 标准库；本次运行环境为 Python 3.12.14。默认配置和输出分别为本目录的 `config/transport.json` 与 `results/`，不随启动位置改变。可用 `--config 路径` 指定另一个配置，或用 `--output 路径` 保存到其他目录。默认运行会覆盖同名结果文件。

每组配置给出 `N`、总步数 `steps`、速度 `c`、终止时间 `T`、格式 `scheme`，以及 `[波数编号, 初始振幅]` 组成的 `modes`。时间步为 `T/steps`，Courant 数为 `c*T*N/steps`。正式计算要求其绝对值不超过一；模态编号须为互异整数，满足 `1<=m<N/2`，振幅须为正。每一步使用显式循环，把旧层更新到独立的新列表。

| E017-02 | `cos(2*pi*x)+0.25*cos(8*pi*x)`；`N=40, c=1, T=1, steps=50`；对照同一波形的变化 | 2 |
| E017-03 细化 | 保持同一双模态初值及 Courant 数 0.8；增加 `N=80,160,320`，各用 `steps=5*N/4`；连同 E017-02 的两组构成四级细化 | 6 组新增 |
| E017-03 特殊步长 | 同一双模态初值；`N=40, T=1, steps=40`；`c=-1,0,1`；检查左右整格平移及静止情形 | 6 |

共 26 组真正逐步推进的计算。每次启动还会先检查手算的一步更新、旧层不被修改、正负整格平移、交替模态、超出 CFL 范围的反例、100 组复数模态因子及非法输入；这些内部检查不计入 26 组。

## 输出与量的定义

| 文件 | 保存内容 |
| --- | --- |
| `results/nodes.csv` | 2400 条终止节点记录，含位置、初值、精确终值和数值终值 |
| `results/history.csv` | 3326 条逐层记录，含初始层；最小值、最大值、离散总量、二范数及两种误差 |
| `results/mode_history.csv` | E017-01 与 E017-02 的 1776 条逐层模态测量 |
| `results/modes.csv` | 全部计算的 40 条终止模态测量及解析预测 |
| `results/summary.csv` | 26 组终止误差、全程总量漂移及预测偏差汇总 |
| `results/convergence.csv` | 两种格式的四级最大节点误差、相邻误差比与观测阶 |
| `results/scan.csv` | 两种格式、两个 Courant 数的解析振幅与相速度扫描，共 1604 行 |
| `results/run.txt` | Python 版本、内部检查及每组计算的文字摘要 |

离散总量为 `sum(U)/N`，二范数为 `sqrt(sum(U**2)/N)`；误差使用同一组节点上的精确平移值。总量接近零，因此报告相对初始层的**绝对漂移**，不用相对误差。

模态系数由数值节点投影得到：余弦系数为 `2*sum(U_i*cos(i*theta))/N`，正弦系数同理，其中 `theta=2*pi*m/N`。两系数的平方和开方得到振幅，`atan2` 给出相位。逐层将角度差接到相邻分支并累加，保留传播的整圈数；累计相位差为数值推进量减精确推进量 `2*pi*m*c*t`。振幅比以初始投影为基准。若振幅降到初始投影的 `1e-12` 以下，程序会中止，避免给舍入噪声指定相位；本配置所有测量均通过此检查。

`scan.csv` 是解析公式采样，不能当作实际推进记录。横坐标为 `theta/pi`，零点相速度比取极限一；`theta=pi` 对应退化交替模态，相速度留空。迎风在 Courant 数 0.5 的该端点振幅为零，也不定义相位。图中的离散标记来自 `mode_history.csv` 的实际第一步测量。

细化误差比为上一层误差除以本层误差，观测阶为误差比的以二为底的对数。Courant 数绝对值为一时，格式在精确算术中实现整格平移；浮点更新与三角函数求值仍可能产生舍入误差，不能把它当作一般精度阶的证据。本目录不保存每一层的全部节点场；逐层诊断在每次真实更新后计算，终止场完整保存。
