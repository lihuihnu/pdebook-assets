# 热方程显式格式的步长与稳定性

本实验比较同一个初边值问题在两种时间步长下的结果。位置、时间、温度均无量纲：

$$u_t=u_{xx},\qquad 0\lt x\lt1,\quad 0\lt t\le0.09.$$

两端始终为零，初值为 $u(x,0)=\sin(\pi x)+10^{-6}\sin(19\pi x)$。微小高频分量是初始条件中明确给定的一项，不是随机噪声。解析参考为

$$u_*(x,t)=e^{-\pi^2t}\sin(\pi x)+10^{-6}e^{-(19\pi)^2t}\sin(19\pi x).$$

## 运行

在本目录运行：

```bash
python src/heat_stability.py
```

Python 3.12.14 实际执行通过；求解只用标准库，无安装依赖。脚本按自身位置读取 `config/stability.json`，将结果写入 `results/`，可从其他工作目录启动。请用普通 Python 执行，保留用于核对的 `assert`，不要使用 `python -O`。

固定 $N=20$、$h=0.05$、$T=0.09$。配置分别取 90 步与 60 步，由 $\Delta t=T/M$ 得到 $r=0.4$ 与 $r=0.6$。这个入口有意允许后一组越过通常的稳定步长限制，用于观察增长；不是通用生产求解器。节点值全部由三点公式逐层计算，不用解析解或模态公式代替更新。

## 输出与核对

| 文件 | 内容 |
| --- | --- |
| `nodes.csv` | 两组实验全部时间层的全部 21 个节点：数值值、解析值和有符号误差，共 3192 行数据。 |
| `history.csv` | 每层的物理时间、步长、比例、最大绝对节点误差、最小/最大温度和模态核对误差，共 152 行数据。 |
| `snapshots.csv` | 共同物理时刻 0、0.030、0.060、0.063、0.090 的 10 行摘要，来自完整历史。 |
| `modes.csv` | 两组参数下全部 19 个正弦模态的理论放大因子，共 38 行数据。 |
| `run.txt` | 实际 Python 版本、配置摘要、时刻摘要及检查结果。 |

`error_inf` 是相对连续解析解的最大节点绝对误差。`modal_check_inf` 是相对离散格式双模态闭式解的最大节点差异，二者用途不同。后一个闭式表达式只用于独立检查逐节点更新，不参与求解。两组完整轨迹的最大核对差异分别约为 $1.33\times10^{-15}$、$6.16\times10^{-9}$；后一组终值幅度约为 310，浮点误差也会随不稳定模态增长，核对采用随解幅度缩放的容差。

脚本检查：手算一步、旧层未被原地改写、两个零边界、有限数值、稳定组的非负性与最大值不增，以及所有 19 个模态的一步放大关系。另检查 $N=2$ 时的精确非放大上界为 $r=1$，以免把对所有网格通用的 $1/2$ 误当成每个有限网格的精确上界。

实际运行到 $T=0.09$ 后，两组最大节点误差分别为 $1.055604848\times10^{-3}$ 与 $3.099138494\times10^2$。实验完整推进至终止时刻，没有对温度或误差做裁切、平滑或人工替换。
