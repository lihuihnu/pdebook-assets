# 第27篇配套计算：二维三角形线性有限元

在单位正方形上求解−Δu=f。核心只使用Python标准库；没有NumPy、SciPy或有限元软件依赖。

```bash
python src/triangular_poisson.py
```

入口根据自身位置寻找config/problems.json与results/，可以从其他工作目录运行。也可用`--config`和`--output`指定路径。输入全部检查和求解完成后才创建输出目录；无效输入与非有限结果不会写入半成品。

## 网格与问题

七张网格：中心/偏移内部点的四三角形网格；n=2、4、8、16、统一左下至右上对角线的网格；n=4交替对角线网格。节点从0编号，每个连接记录恰好三个全局编号。正常运行反转每隔一个单元的局部顺序，检查有向几何，而不改变物理网格。

| case | 源项f | 边界 | 精确解用途 |
| --- | --- | --- | --- |
| constant_zero | 1 | 全边界零Dirichlet | 没有提供连续精确解，误差栏为空 |
| constant_lift | 1 | 全边界1+x+2y | 检查已知列移项和离散仿射提升，误差栏为空 |
| affine_patch | 0 | 全边界1+x+2y | 1+x+2y，求解之后核对 |
| linear_source | x+y | 全边界零Dirichlet | 检查非常数载荷积分，误差栏为空 |
| quartic | 2[x(1−x)+y(1−y)] | 全边界零Dirichlet | x(1−x)y(1−y)，检查真实节点/截线误差 |
| mixed_affine | 0 | 左边Dirichlet，其余三边Neumann | 1+x+2y；右/底/顶q分别1、−2、2 |

两端点之外的二维边界数据是外法向导数q=∇u·n。常数q在一条直边上给两个端点各增加qL/2；仅外边界边加项。Dirichlet节点在边界载荷装配后消元，已知列贡献保留。原残差检查自由行，不把已知边界节点的原积分行当作应满足的测试方程。

## 准确积分与代表范围

面积为|d|/2，梯度分母使用有向d。刚度点积乘面积；常数/仿射源项直接使用准确公式。quartic问题的fN_i最高三次，采用三次精确四点规则：重心坐标(1/3,1/3,1/3)权重−27/48，(3/5,1/5,1/5)及其三种位置权重各25/48，权重乘物理面积。本篇独立检查以有理数直接积分所有10个次数不超过三的参考单项式，再逐个实际单元核对载荷。负权重是这一准确积分规则的系数，不是负单元面积。

核心求解器只为小规模教学使用稠密消元，配置限定n≤16；它展示装配和边界处理，不是大型网格求解框架。来源中的软件不参与本次计算。

| run.txt | 实际Python版本、数据数量与最大受检残差 |

nodal_error为全部网格节点的最大绝对误差；line_error为x=k/400、y=1/2的401个采样点最大绝对误差。后者不声称是整条连续截线或全区域的精确最大误差。中心点值以有限元函数实际评价；偏移网格中心不是一个节点。常源问题不编造解析参考值。

仿射解在空间内应被准确恢复；曲率例子的误差与残差是不同量。对四级规则网格观测到的二阶趋势，不推广为任意三角形网格的一般定理。数据由实际运行生成，Python版本3.12.14。
