# 第21篇配套计算：Burgers 方程、激波与弱解

程序研究无量纲初值问题 u_t+(u²/2)_x=0，初值在 x<0 为 a、x>0 为 b。整条实线上的熵解用于参考；实际计算截取[-2,2]，外侧分别保持常数a、b，不使用周期边界。终止时间T=0.4，原点恰为均匀偶数网格的界面。

## 运行

本目录内运行，Python 3.10及以上即可，无第三方依赖：

```bash
python src/burgers_volume.py
```

也可从任意位置传入脚本绝对路径。配置与默认输出路径相对于脚本所在文章目录确定；作者仓库与公开读者目录使用完全相同的代码。

```bash
python src/burgers_volume.py --config config/burgers.json --output /tmp/pde-021-results
```

`godunov_flux`先求局部熵解在界面处的状态，再返回物理通量。稀疏波跨过零速度时，界面通量为零。`jump_only_flux`故意把任何左右状态都当作一个间断，只用于反例，不是推荐算法。`one_step`先保存所有面通量，再由相邻单元共用；外侧输入是a、b。`exact_average`按精确激波或稀疏波的各段积分，返回平均值，不用中心点采样替代积分。

固定步长dt=T/M，M向上取整以满足dt max(|a|,|b|)/h≤0.8；h=4/N。全零初值用一步保持不变。每步检查有限数值和实际最大速度的步长条件。配置不满足0<CFL≤1时，在写出结果前拒绝运行。计算中M至多为N/4，初始非恒定区的信息按每步最多一个单元传播，不触及两端；直接核对端单元也始终为a、b。

## 算例与输出

18组推进均明确列于JSON：三组四级网格N=80、160、320、640，分别为Godunov激波(a,b)=(2,0)、Godunov稀疏波(-1,1)、jump-only反例(-1,1)；另六组N=160对照为反向激波(0,-2)、静止激波(1,-1)、负向稀疏波(-2,-1)、正向稀疏波(1,2)、常值(-0.7,-0.7)及全零值。

| 文件 | 数据行数 | 含义 |
| --- | ---: | --- |
| cells.csv | 4560 | 每组终止时刻的所有单元，含左右端点、初始/精确/数值平均与误差 |
| history.csv | 773 | 包括初始层的全部时间层：总量、累计边界输运、总量平衡残差、值域、实际CFL、误差与前一步最大局部残差 |
| summary.csv | 18 | 每组参数与最终误差，另记录全程最大CFL、总量及局部平衡残差 |
| convergence.csv | 4 | 三组四级网格的终止E1误差 |
| characteristics.csv | 6 | g=-sin(x)在xi=0处的特征位置、值、映射导数与斜率，t=0至0.99；这些是解析量，不是PDE离散解 |
| jumps.csv | 4 | 三个下降间断和一个上升间断的速度、跳跃条件残差及熵产生量 |
| hand.csv | 8 | 两种通量在四单元[-1,-1,1,1]上的一步更新，h=1、dt=1/4；Godunov给出[-1,-7/8,7/8,1]，错误通量保持原值 |

`step=n`表示第n层。`previous_step_balance`是刚完成更新中最大的局部残差绝对值，初始层为零；局部残差为h(new-old)-dt(left_flux-right_flux)。没有保存全程逐单元历史，`cells.csv`只保存终止层。

`boundary_exchange`累计dt(F_left-F_right)。`mass_balance`=当前总量-初始总量-累计边界输运；本算例不要求总量恒定。例如二到零的激波总量从4增加到4.8，反向激波从-4减至-4.8。E1=h sum(abs(U-exact_average))；`max_error`是单元平均差的最大绝对值。

本次Python 3.12.14实际运行755次更新。最大总量平衡残差为9.992007221626409e-16，最大局部平衡残差为1.0408340855860843e-17。四级激波E1约为0.03524224、0.01762175、0.00881088、0.00440544；稀疏波约为0.06148958、0.03961346、0.02455903、0.01477133。错误通量四级E1均为0.4；其守恒不代表选中了熵解。精确平均、浮点积分与递推均有舍入误差，未将小残差写成数学上的严格零。
