# 第16篇：周期平流与迎风格式

解无量纲常速问题 `u_t + c u_x = 0`，区间长度一，周期边界。仅存 `x_i=i/N`、`i=0,...,N-1`；`x=1` 不重复存储。精确解是初始函数的周期平移 `g(x-c*t)`。

## 运行

进入本目录后执行：

```bash
python src/advection.py
```

也可从任意目录执行脚本的完整路径。默认配置和结果位置按脚本路径定位，支持 `--config`、`--output`。Python 标准库即可运行；无 NumPy、SciPy、绘图依赖。实际验证环境为 Python 3.12.14，Linux。

输入见 `config/advection.json`。程序先自检，再完成8组计算。它显式检查参数、非有限值、迎风极值界和高频模态预测；失败会抛出异常，不将失败记成成功。

## 算例与边界

| 实验 | 数据与参数 | 检查内容 |
| --- | --- | --- |
| E016-01 | 中心0.35、半宽0.15的六次幂紧支撑脉冲，周期延拓；N=100，c=±1，T=0.4，50步 | 传播方向、周期接缝、最大误差、极值界、离散总量 |
| E016-02 | 初值 `1e-6*cos(pi*i/2)`；N=100，c=1，T=0.8，100步；FTCS和迎风 | 与解析模态放大率比较，保存每层范数。用精确四点序列[1,0,-1,0]生成该初值 |
| E016-03 | 初值 `sin(2*pi*x)`；c=1，T=0.4，Courant=0.8；N=40/80/160/320 | 终止最大节点误差与时空共同细化的一阶收敛 |

迎风生产计算要求 `abs(c*dt/h)<=1`；FTCS特意运行不稳定对照。核心 `upwind_step` 本身不做每步参数检查，入口 `simulate` 负责检查；自检中单独调用它构造超出CFL范围的反例。流入/流出边界在正文中分析，这份程序只实现周期边界，不声称验证了有限区间流入程序。

高频扰动与背景波形分开推进。由于线性，它代表两组背景数值解之差；代码没有靠减去两个大数来提取小扰动。该实验用于验证离散递推，不把随网格改变的高频初值当作固定光滑函数的收敛实验。

## 输出

- `nodes.csv`：8组计算共1000行，保存初值、终止数值解和精确解，含节点坐标。
- `history.csv`：共608行，保存每个实际时间层的最值、节点求积总量、离散二范数、相对初始范数、最大节点误差；两组高频实验额外保存模态预测。
- `summary.csv`：每组配置与检查统计，包括全过程总量最大漂移和极值超出量。
- `convergence.csv`：4级正弦网格误差、前后级比值及观测阶。
- `run.txt`：Python版本、自检与实际运行摘要。

没有保存完整时空节点场；每一层都实际推进并检查，全部终止节点和逐层诊断已保存。文件来自实际运行，不手工填写预计输出。浮点总量漂移按绝对值报告，不用接近零的总量做分母。

自检包括手算一步、正负整格平移与静止、48次独立二项卷积对照、200次FTCS复指数闭式对照、交替模态超CFL反例以及非法参数拒绝。复数仅用于自检，正文核心更新只用实数、列表和循环。

两张文章图由作者侧绘图脚本读取上述CSV生成。读者可直接运行求解程序并查看数值文件，不需安装绘图库。守恒、稳定与误差是不同检查；本实验不涉及性能排名，也没有声称通过实际知乎预览。
