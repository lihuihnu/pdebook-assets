# 第14篇：隐式 Euler 与 Crank–Nicolson

在本目录运行：

```bash
python src/heat_implicit.py
```

核心求解仅用 Python 标准库，不需要 NumPy、SciPy 或绘图库。实际运行环境为 Python 3.12.14。程序相对于自身位置查找配置和结果目录；也可用 `--config` 与 `--output` 指定路径。使用普通 Python 运行，不加会禁用断言检查的 `-O`。

## 数学问题

无量纲单位区间上的热方程 u_t=alpha*u_xx，两端温度固定为零；alpha=1，N=20，h=0.05，T=0.1。全部初始节点与两个边界节点直接赋值。

- E014-01：g(x)=sin(pi*x)+0.01*sin(19*pi*x)。显式 Euler（FE）取100步、dt=0.001、r=0.4；隐式 Euler（IE）和 Crank–Nicolson（CN）各取10步、dt=0.01、r=4。比较高频衰减、终止时刻误差与推进次数，不据此声称相同精度或墙钟加速比。
- E014-02：g(x)=sin(pi*x)，固定空间网格，IE/CN各运行5、10、20、40、80步。用空间离散系统的精确时间解隔离时间误差，并另存相对于连续PDE解的总误差。

完整参数见 `config/implicit.json`。程序有意让隐式时间步超过显式稳定上限；FE对照仍要求 r≤1/2。更改网格后须保证初始模态编号小于N。

## 实现与参考值

主算法在物理节点上构造右端，显式执行三对角消元和回代。每个固定参数的隐式算例只分解一次左端矩阵，此后复用主元与消元乘子；没有显式求逆、库内PDE求解器、滤波或未说明的阻尼步骤。

参考值分为三类：

1. 连续PDE解：每个m模态乘 exp(-alpha*(m*pi)^2*t)，用于 `pde_max_error`。
2. 空间离散后的精确时间解：乘 exp(alpha*N^2*lambda_m*t)，lambda_m=-4*sin(m*pi/(2*N))^2，用于 `time_max_error`。
3. 完全离散模态闭式解：乘 G_m^n，只用于独立核对逐节点求解，不用于生成数值解。

时间误差为全部节点的最大绝对差。`modes.csv` 的系数来自实际节点解的离散正弦投影，`normalized` 为系数除以已知初始系数，保留符号。后期极小系数可能受浮点投影误差影响，不作为高精度相对误差证据。

代数残差为每步 `A*new-B*old`。`scaled_residual` 用最大绝对残差除以所有行的最大尺度；每行尺度取右端绝对值加上左端各项绝对值之和，并以1作为整体尺度下限。它衡量已组装方程的求解精度，不等于PDE误差。

E014-01的终止PDE最大误差：FE为1.062511783011e-3，IE为1.815643280566e-2，CN为1.240841990730e-3。E014-02最后一次减半的时间误差比：IE为1.9897848，CN为4.0001982。全部结果均来自已执行的程序。

运行时先检查手算二元系统、输入不被改写、q=0和单内部节点，再检查N=2、3、20，r=0.1、4、100下两种隐式方法的全部模态，共132次一步传播核对。正式轨迹检查零边界、有限值、离散二范数不增、模态闭式对照和代数残差。FE/IE另外检查非负初值的非负性及上界。所有检查通过后才写结果。
