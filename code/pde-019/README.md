# 第19篇配套计算：有限体积格式与数值通量

程序用共享界面通量更新单元平均，对比中心通量与经典 Lax–Friedrichs（LF）通量。核心只使用 Python 标准库。从本目录运行：

```bash
python src/finite_volume.py
```

默认读取 `config/fluxes.json`，将八份 CSV 写入 `results/`，在终端输出摘要。可用 `--output 新目录` 保存复算结果，或用 `--config 配置路径` 指定参数。`results/run.txt` 保存本次实际运行的终端输出。计算采用双精度浮点数，CSV 保留默认浮点表示，没有手工修整尾数。

## 数学问题与算法

所有传播算例均为无量纲单位周期区间上的 `u_t + c*u_x = 0`，初始条件 `u(x,0)=g(x)`，周期条件 `u(x+1,t)=u(x,t)`。初值有三种：`1+0.8*cos(2*pi*x)`、每个周期的 `[0.2,0.43)` 上为一而其余为零的脉冲、常数二。终止时刻均为 `T=0.2`。网格包含 N 个宽度 `h=1/N` 的单元，`dt=T/steps`，`nu=c*dt/h`。

`values[i]` 是单元平均，`fluxes[j]` 是位于 `x=j*h` 的界面通量。左右端点代表同一周期界面，因此只计算一次并复制到列表另一端。所有通量均从旧时间层求出，再执行 `U_new=U_old-dt/h*(F_right-F_left)`。

中心通量为 `c*(left+right)/2`。经典 LF 通量为 `c*(left+right)/2-h/(2*dt)*(right-left)`；此处耗散系数为 `h/dt`，不是取 `abs(c)` 的局部 LF 通量。中心通量对应的 FTCS 更新在固定非零 nu 的细化路径上不稳定，程序保留它用于比较。LF 的正常算例要求 `abs(nu)<=1`；配置中只有 `pulse_lf_overstep60` 明确设置 `allow_cfl_violation=true`，故意越过这一界限作反例。非有限数会触发错误，不会被截断或替换。

精确解为 `g(x-c*t)`。光滑波平均由解析 sinc 公式计算；脉冲平均由周期累计积分在单元两端的差除以 h 计算。初始值和误差参考值都用精确单元平均，不用中心点采样。脉冲初始总量为0.23，光滑波为一，常数算例为二。浮点求积中的舍入可能使本应等于零或一的值略有偏差。

## 实验安排

| ID | 内容 | 参数 |
| --- | --- | --- |
| E019-01 | 四单元手算与给定界面通量的总量平衡 | 手算 N=4、c=1、dt=1/8；另含非均匀开放边界和故意破坏周期端点的代数例子 |
| E019-02 | 波形、总量、传播方向和取值范围 | N=40、c=1、nu=1/2 的光滑波/脉冲/常数与两种通量；c=-1 的 LF 光滑波/脉冲；N=60、nu=1.2 的 LF 脉冲反例 |
| E019-03 | 固定步长比的光滑误差与整格平移对照 | LF 的 N=40、80、160、320，nu=1/2；另有 N=40、nu=1 的光滑波 |

传播算例共13组。`smooth_lf_40` 同时用于 E019-02 与 E019-03，不重复运行。反向传播取 `c=-1`，其余均为 `c=1`。`nu=1` 时 LF 更新退化为向右移动一个单元，此时计算应与精确平均平移一致到舍入量级；这不是一般步长下的精度结论。

## 输出文件

| 文件 | 数据行数 | 内容 |
| --- | ---: | --- |
| cells.csv | 980 | 每组终止时刻的全部单元：几何信息、初始平均、精确平均、数值平均及二者之差 |
| history.csv | 383 | 每组的全部时间层，含初始层：总量、相对初始总量的漂移、最小/最大值、最大误差和加权绝对误差和 |
| faces.csv | 1986 | 每组第一次和最后一次更新所用的 N+1 个界面通量 |
| updates.csv | 1960 | 对应上述两次更新的各单元旧值、新值、左右通量、总量改变量、净流入量和平衡残差 |
| summary.csv | 13 | 参数、终止时刻误差与范围、全程最大总量漂移及全程最大单元平衡残差 |
| convergence.csv | 4 | 光滑 LF 细化结果、相邻误差比和以二为底的比值对数 |
| hand.csv | 4 | 正文四单元手算逐行结果 |
| boundary_examples.csv | 7 | 非均匀开放边界及故意破坏周期端点的两组代数更新 |

`faces.csv` 和 `updates.csv` 的 `step=n` 表示从第 n 层推进到第 n+1 层；它们只保存首末更新，不能视为全程界面历史。`history.csv` 的 `step=n` 则记录第 n 层自身。`mass_drift` 为当前总量减初始总量。`max_error` 为最大平均值误差，`l1_error` 为 `h*sum(abs(U-exact_average))`。

局部平衡残差定义为 `width*(new-old)-dt*(left_flux-right_flux)`。`summary.csv` 的最大残差在全部时间步中累积，首末之外的逐单元记录不另保存。`boundary_examples.csv` 只检查给定通量的更新代数：开放边界总量应增加0.04；周期右端故意多加0.1的通量后，总量应减少0.0125。后者是错误边界的诊断例子，不是另一个正确的周期求解器。

## 实际结果与使用范围

本次使用 Python 3.12.14。13组算例的最大总量漂移为 `2.220446049250313e-16`，最大单元平衡残差为 `6.938893903907228e-18`。这核对了共享通量的代数平衡，不能据此认定所有算例稳定。

N=40、nu=1/2 的脉冲：中心通量的终止值范围约为 `[-1.331665241, 2.017777934]`，LF 约为 `[0.000000011, 0.856966308]`，两者总量都为0.23。光滑 LF 的四级最大误差依次为 `0.1101793803, 0.0570924235, 0.0290693720, 0.0146684967`，相邻误差比趋近二。nu=1 的光滑对照最大误差为 `1.110223024625e-15`。nu=1.2 的脉冲出现约 -1.594 的负值，尽管总量仍守恒。
