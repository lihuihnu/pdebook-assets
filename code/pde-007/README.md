# pde-007：一维 Poisson 方程的第一个数值解

这是《把方程算明白》第 7 篇的公开配套代码。

对应算例：

$$-u''(x)=2,\qquad 0<x<1,$$

$$u(0)=0,\qquad u(1)=0.$$

取 `N=4`、`h=1/4`，内部未知量为 `U_1,U_2,U_3`。程序直接使用正文推导出的 3×3 三对角系数矩阵，并用一个仅供这个小系统教学使用的直接高斯消元函数求解。

## 文件

```text
code/pde-007/
  README.md
  src/
    solve_poisson_1d.py
  results/
    n4_solution.csv
```

## 运行

从公共仓库根目录运行：

```bash
python3 code/pde-007/src/solve_poisson_1d.py
```

只需要 Python 标准库，不依赖 NumPy、SciPy 或其他第三方 Python 包。

程序会重新写出：

```text
code/pde-007/results/n4_solution.csv
```

## 数值检查

程序使用断言核对：

- 手算内部解 `3/16, 1/4, 3/16`；
- 两个零边界值；
- 三条内部离散方程；
- 解析解 `u(x)=x(1-x)` 在全部节点上的值。

这个算例的节点值恰好与解析解一致，是因为三点二阶中心差分对该二次函数的二阶导数恰好精确，不能推广为一般问题没有离散误差。

## 说明

这里的高斯消元只用于把第一个有限差分线性系统完整算出来，并不是大规模 PDE 线性系统的求解建议。
