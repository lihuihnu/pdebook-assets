# 第28篇配套计算：同一Poisson问题的三种节点离散

核心计算仅使用Python标准库。求解−u''=f，区间(0,1)，两端零Dirichlet；扩散系数为一。有限体积明确使用节点未知量和相邻节点中点构成的对偶控制体，不是单元平均版本。

进入本目录后运行：

~~~bash
python src/compare_poisson.py
python src/plot_comparison.py --results results --output figures
~~~

核心入口也可从其他目录运行，通过自身位置寻找config/和results/。参数--config与--output可覆盖路径。绘图只读CSV，依赖Matplotlib；参数--results与--output可覆盖路径。实际版本Python 3.12.14、Matplotlib 3.10.8。

## 问题与配置

13张网格：均匀N=4、8、16、32、64；平方加密与交替扰动N=4、8、16、32。配置用有理数字符串记录坐标，计算时转换为浮点数。

- uniform：x_i=i/N。
- graded：x_i=(i/N)²。
- alternating：x_i=[i+(i mod 2)/5]/N，配置中的N均为偶数，端点保持0和1。

三种源项f=1、x、x²，精确解分别为x(1−x)/2、(x−x³)/6、(x−x⁴)/12。每张网格、每个源项分别使用fd、fv、fe，合计117组求解。

内部矩阵均采用左右差商之差：对角1/h_L+1/h_R，相邻项−1/h_L、−1/h_R。三个右端分别为控制体长度乘节点源项、准确控制体积分、准确帽函数加权积分。边界值为零，无已知列非零贡献。核心求解采用显式三对角前消元与回代，正文第一段函数另直接计算固定四单元系统。

五点Gauss规则在精确算术中准确积分不超过九次的多项式。源项最高二次，帽函数载荷最高三次，分片线性重构与四次精确解之差的平方最高八次，均在规则的准确范围内。保留浮点舍入影响。误差参考值仅用于计算后核对，不参与离散载荷或解的形成。

| run.txt | 实际Python版本、问题定义、行数和最大代数残差 |

节点误差核对节点值；L2误差核对三者采用同一分片线性重构后的函数。不能比较一个方法的节点误差与另一个方法的函数误差。准确积分的一维常系数P1具有精确节点值；不表示区间内部精确，也不推广到二维。

边界通量由相邻中点通量及半控制体源量重构，不是精确边界导数：左Q_0=Q_{1/2}−左半源量，右Q_N=Q_{N−1/2}+右半源量。全区间残差因此与内部控制体残差之和一致；只加内部控制体不能声称已覆盖全区间。FV的局部平衡不自动保证通量或函数误差为零。

配置必须有效、计算必须完成且有限，之后才创建输出目录。无效方法、网格、源项与细化顺序明确报错，不留下半成品。没有数值软件参与求解。
