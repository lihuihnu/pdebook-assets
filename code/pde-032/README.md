# 第32篇：网格和时间步应该多细

核心仅依赖Python标准库。热方程数据来自实际逐步求解，连续/半离散闭式解只测量误差；有限元数据来自准确多项式载荷装配和消元，准确解只用于核对。

## 运行

在本公共仓库根目录：

```bash
python code/pde-032/src/mesh_timestep.py
python code/pde-032/src/plot_mesh_timestep.py
```

第一条生成13份CSV与日志；第二条需要Matplotlib，生成两PNG及两图件矢量PDF。配置为本目录config/problems.json。核心也支持--config与--output。实际运行Python3.12.14、Matplotlib3.10.8；不以W代替运行时间。

## 数学问题

E032-01：无量纲热方程u_t=u_xx，0<x<1，0≤t≤0.1；两端为0，初值sin(πx)。九个N与九个M组成81个隐式Euler候选，每步解内部三对角系统。固定步长下重用一次分解。另有N=10,20,40,80,160、M=3N²/5的显式和隐式Euler联合路径，共91组。显式路径ρ=1/6满足稳定限制。

误差为T=0.1时的最大节点误差。V_h=e^(-λ_h T)sin(πx_i)是时间准确的半离散参考，λ_h=4sin²(πh/2)/h²。error_inf比较连续准确解，space_error_inf比较V_h与连续解，time_error_inf比较实际输出与V_h；它们不等于全过程或连续重构误差。BE本例两项同号，FE可相消。last_steps保存最后更新前后向量以复算残差。

E032-02：同一热问题N=32，初始试算dt=.02，误差率σ=.02,.005,.001。一完整步和两半步得到eta，采用eta≤σdt；接受两半步，否则从同一状态重试。全部试算中点状态和控制字段均保存；首个拒绝、首个接受、末次试算额外保存全向量。σT是指标预算，不是已证明的最终误差上界。步长下限与试算预算耗尽均明确报错。

W定义为内部未知量数乘更新/系统求解数，不计分解、读写、绘图、硬件和内存开销。固定步为(N−1)M；自适应步包括每次接受或拒绝试算的三个求解。最严格自适应组W=160146，未显示比达标固定步候选更低的成本，不能宣称自适应总是更快。

E032-03：-u''=-12x²，0<x<1，边界0与1。常系数一维线性FEM，载荷准确积分，准确节点值为x⁴。每次重新装配与求解，再对最大η_K=1.5(b−a)²b²的单元二分。曲率由源项给出，不用准确解填入解向量。该插值界依赖当前一维常系数、准确载荷与节点精确性，不是一般PDE残差估计器。目标.02,.005,.001分别比较局部网格、同单元数均匀网格与全区间曲率界要求的均匀网格。

连续最大误差由每个单元的端点与内部驻点核对；mesh_profiles的1001个重构点供绘图，不以采样最大值替代严格极值计算。节点误差为舍入量级仍可有单元内部误差。
