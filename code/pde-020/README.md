# 第20篇配套计算：迎风通量重新看线性平流

核心程序只使用 Python 标准库。从本目录运行：

```bash
python src/upwind_volume.py
```

程序读取 `config/upwind.json`，把九份 CSV 写入 `results/`，终端输出摘要。`--output 新目录` 可保存复算结果，`--config 配置路径` 可指定参数。`results/run.txt` 保存本次实际摘要。所有数值由双精度浮点计算产生，CSV没有手工修整尾数。

## 问题与离散

无量纲单位周期区间上的 `u_t + c*u_x = 0`，初始条件 `u(x,0)=g(x)`，周期条件 `u(x+1,t)=u(x,t)`。精确解为 `g(x-c*t)`。每个单元宽度 `h=1/N`，时间步 `dt=T/steps`，带符号的距离比 `nu=c*dt/h`，无符号比为 `rho=abs(nu)`。

传播算例的初值有三种：余弦波 `1+0.8*cos(2*pi*x)`、每个周期 `[0.2,0.43)` 上为一的脉冲、常数二。初始和参考值都由精确单元积分计算：余弦用 sinc 因子，脉冲用周期累计积分的端点差除以宽度。与中心点采样的区别另在四单元例子中比较。

迎风通量在 c 非负时为 `c*left`，c 为负时为 `c*right`。所有界面只由旧时间层计算；周期首尾共用一份通量。单元按 `U_new=U_old-dt/h*(F_right-F_left)` 更新。保留 h、dt 参数是为了与经典 LF 通量使用相同接口，迎风通量自身不依赖它们。

LF 对照采用 `c*(left+right)/2-h/(2*dt)*(right-left)`，与第19篇相同。它不是把耗散系数改成 abs(c) 的另一种实现。两种传播算法都要求 `abs(nu)<=1`，只容许1e-14的浮点判定余量；非有限计算会报错，不会被修剪或替换。长距离平移在下述单步代数比较中单独考察。

## 三组实验

| ID | 内容 | 数据 |
| --- | --- | --- |
| E020-01 | 正/负/零速度四单元手算；七种有向平移距离；两次半格与一次整格推进；点值与平均值的不同初始化 | hand.csv、remap.csv、reaverage.csv、interpretations.csv |
| E020-02 | 迎风和LF的脉冲对照，反向跨周期传播、静止与常数 | cells.csv、history.csv、balances.csv、summary.csv |
| E020-03 | 固定rho=1/2的光滑细化，正负整格平移对照 | convergence.csv及传播结果 |

传播共13组：光滑迎风 N=40、80、160、320，c=1、T=0.2、rho=1/2；N=40的迎风/LF脉冲对照采用相同参数；反向迎风的光滑波与脉冲取c=-1、T=0.6、48步，包含跨周期边界；整格对照为c=1、T=0.2、8步的光滑波，以及c=-1、T=0.6、24步的脉冲；另有c=0、T=0.2、16步的迎风/LF脉冲和c=1、rho=1/2的常数算例。配置列出每组的完整参数。

四单元小例子独立于这13组传播：

- `hand.csv` 使用旧平均[1,2,3,2]，h=1/4、dt=1/8，速度分别为1、-1、0。
- `remap.csv` 以[0,1,0,0]重构，比较nu=-1.5、-1、-0.5、0、0.5、1、1.5。`geometric` 通过平移区间与各旧单元的重叠长度精确积分，`nearest_upwind` 直接使用紧邻迎风公式。abs(nu)=1.5的两组故意越过该公式的步长条件，展示其与几何积分不再相同；它们不是受认可的长时间传播算例。
- `reaverage.csv` 初值也是[0,1,0,0]，对应[1/4,1/2)的脉冲。比较两次dt=1/8与一次dt=1/4，均取c=1、终止时刻1/4。`exact` 始终从原始脉冲直接平移，`numerical` 则在每步之后重新求平均。
- `interpretations.csv` 使用通常的[0.2,0.43)脉冲：平均初始化为[0.2,0.72,0,0]，中心采样为[0,1,0,0]。同用c=1、dt=1/8推进一次；两个离散总量分别为0.23与0.25，后者是节点求积值。

## 输出及实际结果

| 文件 | 数据行数 | 含义 |
| --- | ---: | --- |
| cells.csv | 960 | 每组终止时刻的全部单元，含几何、初始/精确/数值平均及误差 |
| history.csv | 461 | 全部时间层，含初始层；总量、总量漂移、值域、最大和加权绝对误差、前一步最大局部平衡残差 |
| balances.csv | 1920 | 每组第一次和最后一次更新的旧值、新值、宽度、步长、左右通量及平衡残差 |
| summary.csv | 13 | 每组参数、最终误差/值域、全程最大总量漂移与局部平衡残差 |
| convergence.csv | 4 | 四级光滑迎风误差、相邻误差比及以二为底的比值对数 |
| hand.csv | 12 | 三种速度的四单元手算 |
| remap.csv | 28 | 七种距离的平移积分与紧邻公式比较 |
| reaverage.csv | 20 | 两次半格与一次整格方案的全部时间层 |
| interpretations.csv | 8 | 两种初始化及一步结果 |

`history.csv` 的 step=n 表示第n层；`balances.csv` 的 step=n 表示从第n层到第n+1层的更新。后者只保存首末两步，不能视为全程逐单元历史。`previous_step_balance` 在初始层为零，其后是刚完成的一步中最大的残差绝对值。局部残差为 `h*(new-old)-dt*(left_flux-right_flux)`。`max_error` 以精确平均为参考，`l1_error=h*sum(abs(error))`；总量用 `h*fsum(values)`。

本次使用 Python 3.12.14。13组传播共448次更新，最大总量漂移为 `1.1102230246251565e-16`，最大单元平衡残差为 `3.469446951953614e-18`。N=40、rho=1/2、T=0.2的脉冲峰值分别为迎风 `0.980438232421875` 和LF `0.8569663083180783`（完整数值以CSV为准），总量均为0.23。

光滑迎风的四级最大误差约为 `0.03840048, 0.01948258, 0.00980708, 0.00491938`，误差比趋近二。正向光滑整格平移最大误差为 `8.881784197001252e-16`，反向脉冲整格平移为 `6.661338147750939e-15`；解析积分的浮点计算也带有舍入误差。零速度迎风保持原值，经典LF仍改变非恒定轮廓，但保持总量。这些结果分别检查不同性质，不能以守恒代替精度或稳定性判断。
