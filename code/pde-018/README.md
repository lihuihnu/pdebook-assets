# 第18篇配套计算：从局部守恒到单元平均

本程序计算常速平流精确解的单元积分。它没有使用差分或有限体积时间推进，不是PDE求解器。核心代码只使用Python标准库；从本目录运行即可：

```bash
python src/cell_averages.py
```

默认读取`config/averages.json`，输出六份CSV到`results/`。可用`--output 新目录`保存复算结果，也可用`--config 配置路径`指定输入。程序用双精度浮点运算，CSV保留Python的默认浮点表示，不手工修整尾数。

## 数学问题

无量纲单位周期区间，方程为`u_t + c u_x = 0`，精确解为`u(x,t)=g(x-c*t)`。初值分别为`1+0.8*cos(2*pi*x)`，以及在每个周期的`[0.2,0.43)`上为一、其余为零的矩形脉冲。终止时刻1.13。周期端点不另设流入值。

空间网格包括10个等宽单元，以及边界为`[0,0.08,0.2,0.31,0.4,0.55,0.7,0.83,1]`的8个非均匀单元。保存界面列表时两端都需要保留，但平均值列表只包含N个单元。速度取1、-1、0；快照时刻取0、0.13、0.31、0.83、1.13。两种初值、两种网格、三种速度共60个快照，包含反向传播、静止和跨周期边界的情况。

累计积分函数F由初值的解析积分计算。单元平均等于`(F(right-c*t)-F(left-c*t))/(right-left)`；界面在`[ta,tb]`内的有向累计输运量等于`F(x-c*ta)-F(x-c*tb)`。矩形脉冲按半开区间定义点值；跳跃点取哪一侧不影响积分。精确量的浮点计算仍可能出现舍入误差。

## 三组比较

| ID | 比较对象 | 文件 |
| --- | --- | --- |
| E018-01 | 光滑波的精确平均与中心点值；N=10、20、40、80、160，c=1，t=0.13 | comparison.csv |
| E018-02 | 两种初值在均匀/非均匀网格上的平均、中心点值和总量 | cells.csv、totals.csv、exact_curve.csv |
| E018-03 | 相邻快照间的单元总量改变量与两侧界面净输运量 | faces.csv、balances.csv |

`cells.csv`有540行，保留左右边界、中心、宽度、平均、点值和单元总量。`totals.csv`有60行，其中`midpoint_total`是把中心点值当作常数高度后得到的总量，不是精确总量。

`faces.csv`有480行，`transport`向右为正；两端分别保存，以便核对周期通量。`balances.csv`有432行，`residual = mass_change - inflow_minus_outflow`。这些时间段只是积分比较区间，没有数值时间步稳定性条件。

`comparison.csv`有5行，`max_gap`为精确平均与中心点值的最大差，`previous_ratio`是上一级差值除以本级差值。观察到约四的比值，对应光滑求积的二阶差异，不是PDE格式的收敛阶。

`exact_curve.csv`只用于图2：余弦波1001个解析点，矩形脉冲6个绘图顶点。脉冲的两个跳跃位置分别保存左右高度，用竖线表示跳跃，不把它画成有宽度的斜坡。

## 本次实际结果

60个快照的最大总量绝对误差为`3.3306690738754696e-16`；432项积分平衡的最大残差为`1.1102230246251565e-16`。矩形脉冲在均匀网格、c=1、t=0.13时，非零平均为0.7、1、0.6（浮点尾数略有差别），总量0.23；中心点采样得到的总量则为0.3。

这些结果用于核对定义和积分实现，不能据此断言某种数值通量稳定、准确或无耗散。图2由以上CSV直接绘制；概念图1不属于计算数据。
