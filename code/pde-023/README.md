# 第23篇：Poisson弱形式的积分核对

无量纲区间[0,1]，-u''=1，u(0)=u(1)=0。给定三个候选函数：

- u=x(1-x)/2，精确解；
- w=min(x,1-x)/4，连接精确解三个节点的折线；
- z=min(x,1-x)/3，通过v1检验、但不是弱解的反例。

本程序只近似积分，不求解有限元系统。Python标准库即可运行，不需要NumPy或Matplotlib。进入本目录后执行：

    python src/weak_form.py

脚本用自身位置定位配置和结果，所以也可以从别的工作目录调用。另存结果：

    python src/weak_form.py --output /tmp/pde023-results

复合中点积分在两半区间各使用m个小段。m取8、16、32、64、128、256、512，所有分段均避开斜率未定义的中点，并与局部测试函数的端点1/8、3/8对齐。

测试函数为v1=x(1-x)、v2=x²(1-x)²、关于中点反对称的x(1-x)(1-2x)，以及在[1/8,3/8]内等于(x-1/8)²(3/8-x)²、段外为零的局部函数。

结果均由程序实际计算：

| 文件 | 内容 |
| --- | --- |
| integrals.csv | 84组左右积分、残差及与解析积分的偏差 |
| exact_integrals.csv | 12组由解析表达式计算的核对值 |
| energies.csv | 21组能量和斜率误差平方积分 |
| profiles.csv | 401个位置的三个函数值 |
| slopes.csv | 402行分段斜率；中点行分别代表左右极限 |
| run.txt | Python版本、问题和实际执行摘要 |

弱残差采用左侧减右侧的符号。积分误差随m变化；候选函数本身不随m改变，不能把这个实验称为有限元网格收敛。反对称测试函数因对称抵消不能区分本例的三个候选；局部测试则能检出直线段与均匀源项不符。

正文数学结论由证明支持。有限个数值检验不等于对所有测试函数成立。图中的折点斜率以空心端点表示一侧极限，不给该处定义导数。
