# 第25篇：单元矩阵怎样装配成整体矩阵

求解无量纲问题 −u''=f，0<x<1，u(0)=u(1)=0。取连续线性有限元，源项分别为1与x，单元积分用精确公式计算。先由固定2×2系统求解，再用普通循环装配一般小网格并消元。解析解只在求解之后用于核对，没有把解析节点值作为求解输入。

在本目录执行：

~~~sh
python src/element_assembly.py
~~~

核心仅需Python标准库，实际运行Python 3.12.14。配置在config/meshes.json，包含六张网格、两个源项、主网格400个等分采样区间。single_third中的1/3是双精度近似；其他配置坐标可由二进制浮点精确表示。

程序保存七份CSV和日志：

| 文件 | 内容 |
| --- | --- |
| elements.csv | 74个单元的局部刚度与载荷 |
| matrix.csv | 12组计算的完整装配矩阵，共890项 |
| loads.csv | 86个全局载荷分量，含端点 |
| nodes.csv | 86个实际求解节点值、解析值和残差；retained标明是否保留该方程 |
| summary.csv | 12组计算的节点误差、内部残差、平方和、二次型与载荷功 |
| profiles.csv | 主网格两个源项的802行折线值、精确值和逐点误差 |
| assembly_trace.csv | 主网格f=1的18次累加，记录原值、增量、新值 |
| run.txt | 运行版本、模型、行数与误差摘要 |

不要要求端点装配行的残差为零：零Dirichlet条件固定端点值，实际测试方程只有内部行。主例f=1的两个内部值为3/32、1/8，端点装配行的残差各为−1/2。完整矩阵是半正定的；消去已知零端点后，内部矩阵才正定。

可指定输出位置，例如：

~~~sh
python src/element_assembly.py --output /tmp/pde-025-results
~~~

完整二维列表与普通消元只服务小规模透明教学，不面向大规模计算。装配函数明确区分常数与线性源项；没有用数值求积近似替代载荷积分。
