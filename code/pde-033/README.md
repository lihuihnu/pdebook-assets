# 第33篇：二维稳态对流–扩散

核心仅使用Python标准库。当前实际环境：Python3.12.14，绘图可选Matplotlib3.10.8。绘图与求解分离，没有Matplotlib也可生成全部数据。所有内部值来自实际离散求解，准确解只用于给定问题数据与测量。

## 完整数学问题

在无量纲单位正方形上求解 `-kappa*(u_xx+u_yy)+bx*u_x+by*u_y=f`，四边均为Dirichlet。速度 `(bx,by)=(1,0.5)`。

- 光滑主例：kappa=0.05，准确解 `x+y+sin(pi*x)*sin(pi*y)`，四边值 `x+y`；源项为 `2*kappa*pi**2*sin(pi*x)*sin(pi*y)+bx*(1+pi*cos(pi*x)*sin(pi*y))+by*(1+pi*sin(pi*x)*cos(pi*y))`。N=8,16,32,64，最大节点误差目标0.06。
- 双线性回归：同系数，准确解与边界 `x+y+x*y`，源项 `bx*(1+y)+by*(1+x)`，N=4,8,16。差分对这个函数准确，近零误差检查编号、移项和求解，不测量一般格式的空间阶数。
- 容差对照：同一光滑N32网格，残差阈值1e-4、1e-7，与主计算的1e-10结果比较。参考仍有可估计的代数误差。
- 薄层对照：kappa=0.01，f=0，N=10，四边均规定 `v(x)=(exp((x-1)/kappa)-exp(-1/kappa))/(1-exp(-1/kappa))`。迎风与中心格式分别求解同一二维问题，连续解与y无关。

迎风后向差分只支持非负速度，负速度明确拒绝；扩散系数必须正且有限。扩展到反向速度要修改对应的迎风方向。内部初值均为零，已知边界固定。


## 结果含义

最大节点误差为内部节点最大差，`error_l2`为面积加权平方和的平方根。光滑N64实际最大误差0.049952707576334854，达到0.06目标；所有主网格的生产求解残差均低于1e-10。当前迎风比较原理给出代数误差界 `2*residual_inf/(bx+by)`。容差对照的宽松求解仍按自己的阈值判断，不把1e-4阈值的结果误标为1e-10精度。

面通量只保存一次，x/y正方向固定。围绕内部节点的h×h控制体覆盖 `[h/2,1-h/2]^2`，源项采用 `h²*f(node)`。局部缺口为净流出减源项，与 `-h²*residual`一致；整体缺口比较该控制区域外围数值通量与离散源项和。它不是物理边界上的连续通量误差。

薄层中心解残差接近零而有45个负内部节点；迎风解有界但明显展宽，最大节点误差约0.0907232。小残差、值域保持和连续问题的精度是不同检查。本实验不包含物理观测、模型确认、时间推进或求解器耗时排名。
