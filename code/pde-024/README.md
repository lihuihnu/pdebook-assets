# 第24篇：一维线性有限元与节点基函数

问题为无量纲区间[0,1]上的−u''=1，u(0)=u(1)=0，解析解u=x(1−x)/2。主网格为0、1/4、1/2、1，两个内部节点值为3/32、1/8。

进入本目录运行：

    python src/linear_elements.py

只需要Python标准库。程序根据自身位置寻找配置，从其他工作目录调用也可运行。另存输出：

    python src/linear_elements.py --output /tmp/pde024-results

程序先验证节点严格递增、端点为0和1、数据有限、系数数量正确及零边界。教学函数hat_value和from_hats使用已验证的节点与系数；单独调用前应先执行validate_values(nodes, values)。它们展示全局基函数展开；local_value使用单元的两个端点独立求值。

完整配置见config/meshes.json。八张网格包括主非均匀网格、只细分第一个单元的网格，以及2、4、8、16、32、64个等长单元的网格。

| 输出 | 内容 |
| --- | --- |
| basis_profiles.csv | 主网格401个位置的基函数、加权项、叠加、局部求值、精确解和误差 |
| node_checks.csv | 两个基函数在全部四个节点处的8项取值核对 |
| hand_values.csv | 1/8、3/8、3/4处的基函数值、插值和误差 |
| element_errors.csv | 133个单元的长度、中点误差及斜率误差平方积分 |
| refinement.csv | 八张网格的节点误差、全区间最大误差与斜率误差 |
| weak_checks.csv | 对125个内部节点基函数的左右弱积分与残差 |
| single_hat.csv | 内部节点a=1/4、1/2、3/4时，三个单系数弱方程的积分及实际解 |
| run.txt | 运行环境和执行摘要 |

一般网格直接使用已知解析解的节点值做插值，没有装配或求解整体线性系统。只有single_hat中的单系数例子由源项面积除以导数平方积分求出未知数。

当前抛物线的每段误差是(x−a)(b−x)/2，最大值恰在单元中点，所以输出的max_error是本例全区间最大误差，不是任意采样最大值。斜率误差通过多项式原函数准确积分。

本篇证明了在一维常系数Poisson、连续线性元且积分准确时，插值等于离散弱解；不能把这一性质推广到任意方程、维度或数值积分。节点值精确也不代表节点间的函数精确。
